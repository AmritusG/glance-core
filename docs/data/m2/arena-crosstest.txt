How bytes are compared: Swift's JSONEncoder writes object keys in a per-process hash-seeded
order (measured: 4 runs of one program, 4 different key orders), so its production bytes are
not reproducible even by Swift. The oracle therefore also writes each sample with .sortedKeys;
Rust's sorted encoding (swift_json::to_vec_sorted) is compared byte for byte with it. Value
formatting (\/ escapes, control escapes, integral doubles without .0, e+16 / e-07 exponents,
Date via the 2001 reference date) is identical in both orders. Rust's production files write
keys in declaration order.
